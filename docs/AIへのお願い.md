# AIへのお願い（ゆめかわ★ウイルス・ぽっぷ）

作業の前に、このファイルと仕様書（docs/terafes_03_03_仕様書.md）を読んでください。

1. 仕様書どおりに作る。数値・データの形・関数の名前は変えない。
2. 直すのは、頼まれたファイルだけ。ほかのファイルは読むだけにする（持ち主は仕様書 2.2）。
3. ほかのファイルの関数は、仕様書 10.1 にあるものだけを使う。
4. トップレベルに新しい名前（const・function）を増やさない。ほかのファイルと同じ名前は使わない。
5. 見本（sample/）は読むだけで、直さない。参考にしてよい。
6. 頼まれた作業と関係ない所は、書きかえない。
7. コメントは「// ★」の形で、中学生にも分かる言葉で付ける。
8. 仕様書と合わない所・迷った所は、勝手に決めずに報告する。
9. コミット・プッシュはしない。
10. 終わったら、変えた所と、確かめ方を短く報告する。

---

## 使い方（班のメンバーへ）

AIに頼むときは、次の形で書く。

```
docs/AIへのお願い.md を読んでから、作業してください。
仕様書 （章番号） のとおり、（やりたいこと）してください（（ファイル名））。
（今回やらないことがあれば）は、今回はしません。
```

例）
```
docs/AIへのお願い.md を読んでから、作業してください。
仕様書 3.3 のとおり、セレクト画面の曲カードを SONGS から作るようにしてください（screens.js）。
```

- AIがリポジトリのファイルを読めないとき（チャットにファイルを添付して頼むとき）は、このファイルの1〜10を、プロンプトの上に貼る。
- AIの報告（変えた所・確かめ方・迷った所）は、プルリクエストの説明に貼る。
- このファイルを変えるときは、全員で相談する。
