Gitの運用ルール　ゆめかわ★ウイルス・ぽっぷ
========================================

GitHub と SourceTree で運用します。
作業のたびごとに、新しいブランチを作成して、下記の手順で進めます。


＜ファイルを作成／修正するとき＞

①ブランチを作成する

　＜SourceTreeで＞
　ブランチボタンをクリック
　新規ブランチ：に、他の人とかぶらない名前を入れて、ブランチを作成をクリック
　例）matsui-index　（名前-作業するファイル名など）

②このブランチで作業する

　自分の担当ファイルを修正（例：index.html、game.js）
　※同じファイルを複数の人が触らないように注意！
　メッセージをちゃんと入れて、コミット

③プッシュする

　＜SourceTreeで＞
　プッシュボタンを押すのでもいいし、
　matsui-index　ブランチ上で右クリック－プッシュ先－origin　としてもよい
　（２個目の方は、既に matsui-index にチェックが入っているのでラク）

④プルリクエストを送る＜GitHub上で行う＞

　Pull requestsタブをクリック
　New pull request ボタンをクリック
　base:main ← compare:matsui-index　この右側を自分のブランチ名にして
　下の差分を確認して
　Create pull request　ボタンクリック
　下のCreate pull request　ボタンクリック
　→これでお願いが送れました。


＜プルリクエストを確認してマージするとき＞

★プルリクエストをリーダーなどが確認してマージする＜GitHub上で行う＞

　Files changedタブで確認して、OKだったら
　Submit review ボタンクリック、コメント入れて Submit review
　Merge pull request ボタンクリック、Confirm merge ボタンクリック

※リーダーの確認項目（コードを全部読まなくてもよい）
　・動作確認：トップから、曲を選び、プレイ、リザルトまで通して遊べる
　・変更の内容を、本人が自分の言葉で説明できる
　・担当外のファイルを変更していない

（プルリクエストしないでmainにマージしたいときは、③④の作業をせず下記を実行
　＜SourceTreeで＞
　mainをダブルクリックしてチェックアウト
　自分のブランチ側で右クリック－現在のブランチに「自分のブランチ名」をマージ
　そのあと、プッシュする）


＜マージされた内容を取り込むとき＞

①フェッチする

　＜SourceTreeで＞フェッチして最新状態にする（最新状態を確認する）

②mainブランチにチェックアウトしてプルする

　mainの横に数字が出てmainが古くなっていることがわかるので、
　mainブランチをダブルクリックしてmainブランチに切り替えて、
　プルして最新状態にする

③マージされて役目を終えたブランチは削除する

　ブランチ上で右クリック－matsui-index を削除　をクリック
　OKボタンをクリック

※作業のたびごとに新しいブランチを作成して上記の作業をする


＜ブランチで作業中にmainが変更されてそれを取り込むとき＞

①フェッチする

　＜SourceTreeで＞フェッチして最新状態にする（最新状態を確認する）

②mainブランチにチェックアウトしてプルする

　mainの横に数字が出てmainが古くなっていることがわかるので、
　mainブランチをダブルクリックしてmainブランチに切り替えて、
　プルして最新状態にする

③自分の作業ブランチに戻る

　自分のブランチをダブルクリックしてチェックアウト
　→自分のブランチに○がつく

④mainを現在のブランチにマージ

　main を右クリック → 「現在のブランチにmainをマージ」
　これで、自分のブランチにmain の最新変更が取り込まれる。
