## 2. 押さえる流れ（1曲遊ぶあいだ）

```
タイトル ──Enter──▶ セレクト ──Enter / 1〜3──▶ Game.start(k)
                                                  │ 譜面を作る（chart）
                                                  │ レーンを作る（View.build）
                                                  │ Screens.show('play')
                                                  ▼
                                    loop（毎フレーム）
                                      ├ Sound.sched … 0.3秒先までの音を予約
                                      ├ ウイルスの出現・移動・ミス
                                      └ 終わったら finish
                                                  │
           D F J K ─▶ Screens のキー振り分け ─▶ Game.key ─▶ press（判定・得点・音）
                                                  │
                                                  ▼
                     Game.onFinish(result) ─▶ showResult
                                                  ├ Ranking.add … 「ななし」で登録
                                                  ├ ランキング表示（10位以内なら名前の入力欄）
                                                  └ Screens.show('result')
```

**いちばん大事なのは、ファイルをまたぐのが「仕様書 10.1 の関数だけ」になっていることです。**

- screens.js → game.js：`Game.start(k)`、`Game.stop()`、`Game.key(code)`
- game.js → screens.js：`Game.onFinish(result)`、`Screens.show('play')`
- screens.js → ranking.js：`Ranking.add` / `setName` / `top10` / `todayTop` / `reset`

`Game` の中の状態 `S`（560行）は、外からは見えません。外に出すのは、終わったときの `result` だけです。
