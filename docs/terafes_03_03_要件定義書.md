| 参照資料 | 学園祭展示企画書、サンプルアプリ（DOM版） |

## 1. 目的と範囲

- **目的**：学園祭で展示するリズムゲームを、授業の実習時間内（3名×各4時間）で実装できる最小限の機能で作る。
- **作るもの**：曲を選んで遊べ、叩いた音がメロディになり、曲ごとのランキングまで動く、完全ローカルのブラウザゲーム。難易度は曲ごとに分ける。
- **作らないもの**：5章を参照。

## 2. 前提・制約

| 項目 | 内容 |
|---|---|
| 開発言語 | HTML5、CSS3、JavaScript |
| 描画方式 | DOM + CSS（企画書のCanvas APIから変更） |
| 使用しないもの | フレームワーク、外部ライブラリ、画像・音声ファイル、サーバー、データベース |
| 同梱するもの | フォントファイル（丸ゴシック「M PLUS Rounded 1c」、無料で使えるライセンス）。ネットがなくても同じ見た目で表示するため |
| 使用する機能 | キー入力（KeyboardEvent）、Web Audio API、LocalStorage |
| 実行方法 | 展示PCで index.html を開くだけ（完全ローカル） |
| 操作 | キーボードの D・F・J・K（2レーンの曲は F・J）。上段の数字1〜4キーも**併用**できる。テンキーは使わない |
| 使用する曲 | 著作権が切れた作品のみ（必須はきらきら星、ジングルベル、天国と地獄。追加の曲は未定） |
| 工数 | 3名×各4時間（テストは別枠） |

## 3. 機能要件

◎＝必須　○＝できれば（必須がすべて動いてから着手する）

| ID | 機能 | 要件 | 優先度 |
|---|---|---|---|
| F-01 | 曲選択 | タイトル画面とは**別のセレクト画面**に、曲ごとのカード（曲名、星の数、難易度ラベル、レーン数、長さ、使うキー）を並べ、選んだ曲で開始する。必須は3曲（3.1を参照）。矢印キー＋Enter、または番号キーで選べる | ◎ |
| F-02 | ノーツ落下 | 曲ごとの譜面データ（メロディの音符の並び）に従って、ウイルスが画面上部から判定ラインに向かって落ちてくる。音の高さでレーンが決まる。天国と地獄では、ウイルスが2つ同時に落ちてくる場面がある（片方はメロディ、もう片方は和音またはメロディ） | ◎ |
| F-03 | キー判定 | D・F・J・Kキー（数字1〜4も可）でタイミングを判定し、「大優勝！」「神！」「超かわよ！」「ざんねん…（ミス）」を表示する | ◎ |
| F-04 | スコア・コンボ・HP | スコア、コンボ数、サーバーHP（ハートメーター）を表示する。ミスでHPが減る | ◎ |
| F-05 | ゲーム終了 | 曲が終わるか、HPが0になったら終了する | ◎ |
| F-06 | リザルト | 防衛率、ランク、スコアを認定証風に、全ランクで表示する。「もう一回」「曲選択へ」を選べる | ◎ |
| F-07 | ランキング | **曲ごとに**スコア上位10件をLocalStorageに保存し、リザルトに表示する | ◎ |
| F-08 | キャラクター | ピンク・ミントグリーン・イエローの3種のウイルスを表示する。キャラの見た目は全画面で同じにする | ◎ |
| F-09 | BGM・メロディ | BGMはドラムとベースに、**薄く流れるメロディ**を加える（ミスしても曲が分かるようにする）。ウイルスを撃退すると、そのノーツの音が**大きく**鳴る。効果音は別に用意しない。音の大きさやリズムは、遊びながら調整する | ◎ |
| F-10 | 本日のトップ | タイトル画面に「本日のトップ」（その日のハイスコア）を表示する。表示のしかたは仕様書で決める | ◎ |
| O-01 | ヒット演出 | 撃退時に粒がはじけるアニメーション | ○ |
| O-02 | キャラの特徴 | トゲ、針付き帽子、群れなど、企画書どおりの見た目 | ○ |
| O-03 | ランキングのリセット | スタッフ用に、全記録を消せる | ○ |
| O-04 | 追加の曲 | 必須の3曲に加えて、時間が余ったら曲を追加する。曲のデータを足すだけで、コードは変えない。追加する曲は未定（余ってから、曲の候補を考える） | ○ |
| O-05 | ランキング一覧画面 | 全曲のランキングを一覧で見られる画面。タイトル画面と切り替えて表示する案もある | ○ |
| O-06 | ランキングの名前 | ランキングの10位以内に入ったときだけ、リザルト画面で名前（6文字まで）を入れられる。入れなければ「ななし」で登録する | ○ |
| O-07 | セキュリティ豆知識 | リザルト画面に、セキュリティの豆知識を1つ表示する（情報処理科の展示として）。画面の場所は先に用意しておく | ○ |

## 3.1 曲一覧と難易度

| 曲名 | 星 | ラベル | レーン | 長さ（目安） | 優先度 |
|---|---|---|---|---|---|
| きらきら星 | ★1 | やさしい | 2（F・J） | 29秒 | ◎ |
| ジングルベル | ★3 | ふつう | 4（D・F・J・K） | 40秒 | ◎ |
| 天国と地獄 | ★5 | げきむず | 4（D・F・J・K） | 42秒 | ◎ |

追加の曲は未定（時間が余ったら、候補から考える）。

- **難易度の決め方**：レーン数、ノーツの数（密度）、落ちる速さの組み合わせで決める。
- **同時に落ちるウイルス**：天国と地獄だけ、2つ同時に落ちてくる場面を入れて難しくする（F-02）。
- **曲のデータ**：曲ごとに、音符（拍・音の高さ）の並びとして持つ。難易度の数値は、実際に遊んで調整する。

## 4. 非機能要件

| 項目 | 内容 |
|---|---|
| ブラウザ | Chrome |
| 解像度 | 横1920px（画面比率は16:9を想定。ゲーム画面は余白が出ないよう、画面に合わせて拡大縮小する。縦サイズは決めず、テストで確認する） |
| 性能 | プレイ中にカクつかず、30fps以上で動く |
| 音と判定の同期 | 判定の基準時刻は、Web Audioの時計を使う |
| 堅牢性 | LocalStorageが使えなくても、ゲームは最後まで動く |

## 5. 対象外

- 一時停止、設定画面、音量調整
- スマホ・タブレット対応
- サーバー通信、他のPCとのランキング共有
