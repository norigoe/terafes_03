## 1. 位置づけ

要件定義書の各要件（F-01〜F-10、O-01〜O-07、非機能要件）を、画面・動作・データの仕様として具体的に書いたものである。要件との対応は11章にまとめた。

- 数値・計算式・データの形・関数の名前は、**この仕様書どおりに作る**（AIに実装を任せるときも、この仕様書を渡す）。
- 音とリズム（7章）は、あえて詳しく書かない。サンプルを出発点にして、遊びながら調整する。
- 見た目（色・大きさ・配置の細部）は、画面（`index.html`・`style.css`・`result.css`・`chara.css`）で決める。この仕様書には、必要な要素だけを書く。
- 動作の細部で迷ったときは、サンプルの動きを基準にする。

### 2.1 画面の拡大縮小

- 倍率 ＝ min(ウィンドウ幅 ÷ 1067、ウィンドウ高さ ÷ 600)。リサイズのたびに再計算する。

- 16:9以外では上下または左右に余白が出る。余白の色は濃紫（`#2b1f4a`）。

## 3. 画面仕様

### 3.1 画面遷移

画面の名前は、**タイトル画面、セレクト画面、プレイ画面、リザルト画面**（カタカナで統一する）。

画面遷移図・画面一覧・遷移一覧は、別紙「画面遷移図」（この仕様書と同じ回の番号のもの）を参照する。下の表は、その要約である。

| 画面 | 操作 → 移る先 |
| --- | --- |
| タイトル | Enter／あそぶ → セレクト |
| セレクト | 曲を決める → プレイ ／ Esc／タイトルへ → タイトル |
| プレイ | 終了（曲の終わり、HP0） → リザルト ／ Esc → セレクト |
| リザルト | もういちどあそぶ［Enter］ → プレイ（同じ曲） ／ きょくをえらぶ［Esc］ → セレクト ／ タイトルへ → タイトル |

- 表示する画面は常に1つ。画面の `id` は `title`、`select`、`play`、`result`。
- プレイ中のEscは中断。結果は残らず、ランキングにも載らない。
- 背景は全画面で共通：パステルのグラデーションに青い格子線を重ね、ハートと星がゆっくり漂う（`#fl`）。白い粒20個も、画面の横幅全体に散らばって降り続ける。タイトル画面では、ハート・星と白い粒を、絵（3.2）の手前に出す（粒の上をクリックしても、下のボタンが押せる）。

### 3.2 タイトル画面（`#title`）

背景は1枚の絵（`images/title.png`）。ロゴ「ゆめかわ★ウイルス・ぽっぷ」、サブタイトル「〜パステルカラーのサイバー防衛戦！キー連打で大優勝★〜」、キャラ3体と名前・セリフ、キーの形の「あそぶ Enter」ボタン、「クリック／Enterでスタート」は、絵に描かれている。その上に、次の3つを重ねる。

| 要素 | 仕様 |
| --- | --- |
| あそぶ（`#go`） | 絵の「あそぶ」ボタンにぴったり重ねた、透明なボタン（文字は読み上げ用に残し、画面には出さない）。押すとセレクト画面へ。マウスを乗せるとカーソルが手の形になる（光や枠は付けない。絵のボタンの形とずれるため） |
| 本日のトップ3（`#today`） | 絵の下の白いパネルに重ねる。見出し「★ 本日のトップ3 ★」の下に、曲ごとの列を難易度順（星の少ない順）に並べ、列ごとに曲名の札と、その日の記録の上位3人を「メダル・名前・◯点」で表示する（8.3） |
| スタッフ用（`#rst`） | 右上の隅に、小さな下線付きの文字ボタン「ランキングをリセット」。押すとパスワードを聞き、合っていれば確認ダイアログの後、全曲の記録を消す。間違い・キャンセルのときは何もしない（パスワードは `screens.js` の `RESET_PASS` で決める） |

- 絵の上の位置は、「絵の上の位置 × 0.638（＝1067÷1672）」で計算する。絵を差しかえて位置が変わったら、`style.css` の `#go`・`#today` の位置を直す。

## 4. 入力仕様

| 画面 | 操作 | 動作 |
| --- | --- | --- |
| タイトル | Enter／あそぶボタン | セレクト画面へ |
| タイトル | リセットボタン | パスワードを入れて、合っていれば確認ダイアログの後、全曲のランキングを消す。間違い・キャンセルのときは何もしない |
| セレクト | ← →（↑ ↓も可） | 選択中の曲を、カードの並び（難易度順）で1つずつ切り替える（端は反対側へ回り込む。2段のときも、上の段の右端の次は下の段の左端） |
| セレクト | Enter／カードのクリック | 選択中の曲（クリックした曲）を開始 |
| セレクト | 数字キー 1〜（曲の数） | 左からその番目のカード（カードの番号）の曲をすぐ開始 |
| セレクト | Esc／タイトルへボタン | タイトルへ |
| プレイ（開始前） | Space | 曲を始める。開始前は、D・F・J・K や数字キーを押しても何も起きない |
| プレイ | 2レーン：F・J ／ 4レーン：D・F・J・K | 左から順に対応するレーンを叩く |
| プレイ | 数字キー 1〜4 | 左から順にレーン1〜4を叩く（レーン数を超える番号は無効） |
| プレイ | Esc | 中断してセレクト画面へ |
| リザルト（名前の入力中） | 文字の入力 | 名前を入れる（6文字まで。日本語入力も可）。D・F・J・K や数字キーは、文字として入るだけ |
| リザルト（名前の入力中） | Enter | 名前を決める。空のときは「ななし」。日本語入力の変換を決めるEnter（`isComposing` が `true`）では決めない |
| リザルト（名前の入力中） | Esc | 入力をやめて「ななし」で決める |
| リザルト | Enter／Esc | もう一回／セレクト画面へ（名前を決めた後） |
| リザルト | タイトルへボタン | タイトルへ（名前を決めた後） |

- 数字キーは上段（セレクト画面は `Digit1`〜曲の数、プレイ画面は `Digit1〜4`）だけを受け付ける。テンキー（`Numpad`）は受け付けない。
- キーの押しっぱなし（リピート）は無視する。
- 一時停止はない。

## 5. ゲーム仕様

### 5.1 曲の設定

セレクト画面では、星の少ない順に並ぶ（表もその順）。番号は `SONGS` の何番目か（8.1、8.2）。

  - 前半〜しめくくりと、1オクターブ上の「そー らー しー」は、拍の頭の音に、`+` で左のレーンにもう1匹足す（音はそのときのコードの根音）。1拍のばす音は、原曲どおりのばす（第4版の、うしろの半拍の伴奏「チャ」はやめた）。
  - 1オクターブ上の「れど ふぁみ れど しら」と「そ れ そ れ…」は、`＝` で落ちる位置を決める（鳴る音は1オクターブ上など。位置は、レーンが左右に動くように選ぶ）。
  - 「そっそ」「しー」「じゃん！」は、`&`（5.2 の 9）で同時に落ちる2匹・3匹にし、どの1匹を叩いても G の和音が鳴る。「そっそ」の長い「そっ」は K＋D と J＋D を交互に4回ずつ、「そ。」は K＋D、「しー」は K＋J、最後の「じゃん！」は3匹同時（D・J・K）。
- 1曲の長さは50秒くらいまでを目安にする（エンターテイナーは、曲を短くしないために少し長い）。

- 難易度は、レーン数・ノーツの数（密度）・落下時間の組み合わせで決まる。数値は、遊んで調整する。

### 5.2 譜面の作成

曲データの `chart`（8.1）から、ノーツの一覧を作る。同じ曲は毎回同じ譜面になる。

1. 1拍の長さ ＝ 60 ÷ BPM（秒）。
2. 準備時間 `lead` ＝ （落下時間＋0.3秒）を1拍単位で切り上げた長さ。
3. 曲データを先頭から読み、休符（`R`）以外の音を1つずつノーツにする。到達時刻 ＝ `lead` ＋ （それまでの拍の合計）× 1拍の長さ。休符は時間だけ進める。
4. **レーン**：曲に出てくる音の高さを低い順に並べ、「何番目の音か」で決める。レーン ＝ 切り捨て（順位 × レーン数 ÷ 音の種類数）。低い音が左、高い音が右。
5. **ウイルスの種類**：レーン番号を3で割った余り（0：ランサム、1：フィッシング、2：DDoS）。
6. **同時に落ちるウイルス**：`chart` で `+` でつないだ音（8.1）は、同じ到達時刻のノーツにする。同じレーンになったときは、あとに書いた方を右隣のレーンへずらす（右端のレーンなら左隣へ）。
7. **音の高さ**：音名から決める（A4 ＝ 440Hz を基準にした平均律）。
8. **`＝` を使った音**：`chart` で `＝` を書いた音（8.1）は、ウイルス1匹のノーツにする。`＝` の左の音で、レーンを決める（4 の「音の種類」にも、左の音だけを数える）。`＝` の右の音（`+` でいくつでも）は、そのウイルスを撃退したときに鳴る音にする（7章）。例）`F#5=A#3+F#4` ＝ F#5 のレーンに1匹落ちてきて、叩くと A#3 と F#4 が同時に鳴る。
9. **`&` を使った音**：`chart` で `&` でつないだもの（8.1）は、`&` で区切った1つずつを、同じ到達時刻のウイルス1匹ずつにする（6 と同じく同時に落ちる。同じレーンになったときのずらし方も 6 と同じ）。1匹ずつに `＝` が使え、その1匹のレーンと鳴る音を 8 と同じに決める（`＝` がなければ、その音の位置で、その音が鳴る）。例）`B5=B4+D5+G5&G3=G2+G3` ＝ B5 のレーン（K）と G3 のレーン（D）に1匹ずつ落ちてきて、K を叩くと B4・D5・G5、D を叩くと G2・G3 が鳴る。

### 5.3 判定

基準時刻は Web Audio の時計（`AudioContext.currentTime`）を使う。曲の開始時刻 `t0` からの経過時間を `t` とする。押したレーンの未処理ノーツのうち、到達時刻との差が最も小さいものを対象にする。

| 判定 | タイミング差 | 基本点 | 表示色 |
| --- | --- | --- | --- |
| 大優勝！ | 0.06秒未満 | 300 | ピンク `#ff4fa3` |
| 神！ | 0.12秒未満 | 200 | 水色 `#3bb8ff` |
| 超かわよ！ | 0.2秒以内 | 100 | 紫 `#9a6bff` |
| ざんねん…（ミス） | 到達から0.2秒過ぎても未入力 | 0 | 灰紫 `#8a7bb0` |

0.2秒の範囲外での空打ちにペナルティはない（何も起きない）。

### 5.4 ウイルスの動き

- 到達時刻の「落下時間×1.15」前に出現させる。
- 縦位置 ＝ 500 − （到達時刻 − 現在の `t`）÷ 落下時間 × 530。到達時刻に判定リング（y=500）へ重なる。
- 撃退またはミスで画面から消す。

| スコア | 基本点 ＋ min(コンボ数, 50) × 2 を加算 |

### 5.6 ゲーム終了

次のどちらかで終了し、リザルト画面へ移る。

- 終了時刻（`lead` ＋ 曲の長さ ＋ 1秒）を過ぎた。
- サーバーHPが0になった。

### 5.7 防衛率とランク

防衛率 ＝ 撃退したノーツ数 ÷ 全ノーツ数 × 100（四捨五入）。HPが0で途中終了した場合も、分母は全ノーツ数のままとする。

| ランク | 防衛率 | コメント |
| --- | --- | --- |
| S | 95%以上 | 超大優勝★ |
| A | 85%以上 | 大優勝！ |
| B | 70%以上 | 神！ |
| C | 70%未満 | まだまだかわいい |

- 防衛率は、四捨五入してからランクの表と比べる（例：天国と地獄で226匹撃退＝94.17%→94%で A、227匹＝94.58%→95%で S）。

## 7. サウンド仕様

すべて Web Audio API で合成する（音声ファイルなし）。具体的な音色・音量・パターンは、見本 `sample/` を出発点にして、**開発中に遊びながら調整する**（この仕様書では細かく決めない）。

| 項目 | 仕様 |
| --- | --- |
| BGM | ドラム・ベース・和音。曲のテンポ（BPM）に合わせて鳴らす。ベースは各コードの根音、和音は2拍目と4拍目に鳴らす。コード進行は曲データの `chords`（8.1）を使う（`chords` がない曲は C→Am→F→G のくり返し） |
| 曲の始まり | 小節の頭を、メロディの始まりにそろえる。準備時間のうち1小節に足りない分は鳴らさず、1拍目からリズム（ドラム）だけを鳴らす。ベースと和音はメロディと一緒に入る |
| 曲の終わり | 最後のコードの間はリズム（ドラム）だけにして、曲の終わりで止める |
| 伴奏なし（`R`） | `chords` で `R` と書いた間は、ベースと和音を鳴らさない（リズムだけ）。弱起の曲の最初の小節に使う |
| 薄いメロディ | 曲のメロディを、BGMとして薄く流し続ける。ミスしても、曲が分かるようにするため。`+` でつないだ音は、先に書いた音（メロディ）だけを鳴らす。`＝` の和音は、右に最後に書いた音だけを鳴らす。`&` でつないだときは、最初の1匹（いちばん左に書いたもの）だけを、同じ決まりで鳴らす |
| 撃退したとき | そのノーツの音を、薄いメロディより大きく鳴らす（ヒットすると、メロディが目立つ）。`＝` の右に書いた音がいくつかあるときは、全部を同時に鳴らす（和音）。重なって大きくなりすぎないように、1つずつの音は小さくする（音量 ＝ 0.3 ÷ √音の数。1つなら0.3、4つなら0.15）。`&` でつないだときは、叩いた1匹の音（和音）だけが鳴る。音の長さは、そのノーツの長さ（最大0.6秒） |
| ミスしたとき | 効果音はない。薄いメロディは流れ続ける（画面の揺れは3.4） |
| 同時に落ちるウイルス | ねこふんじゃった・エンターテイナー・天国と地獄。それぞれ、自分の音が鳴る（`+` の2つ目は、メロディと一緒に鳴らす和音の音。ねこふんじゃったは「じゃった」のチャッの低い音、エンターテイナーはフレーズの頭・終わりの和音のもう1つの音、天国と地獄は拍の頭のコードの根音。天国と地獄の終わりの `&` の所は、どの1匹も G の和音） |

- AudioContext は、最初の曲の開始操作（キーまたはクリック）のときに作る。

## 8. データ仕様

### 8.1 曲データ（`charts.js` の `SONGS`）

`SONGS` は曲の配列。曲を増やすときは末尾に1つ足す（並びは変えない）。

| 項目 | 内容 |
| --- | --- |
| `name` | 曲名 |
| `star` | 星の数（1〜6） |
| `label` | 難易度ラベル |
| `col` | ラベルの色（例：`'#3fbf7f'`） |
| `lanes` | レーン数（2 または 4） |
| `bpm` | テンポ |
| `fall` | 落下時間（秒） |
| `chart` | 譜面。スペース区切りの「音名:長さ」の並び |
| `chara` | セレクト画面のカードに出すキャラの種類（0：ランサム、1：フィッシング、2：DDoS） |
| `santa` | 省略可。`true` にすると、フィッシングがサンタの帽子になる（カードとプレイ中。6章） |
| `chords` | 省略可。伴奏のコード進行。スペース区切りの「コード名:長さ」の並び（7章） |

`chart` の書き方：
- 音名 ＝ ドレミ（C D E F G A B）＋ オクターブの数字。`C4` ＝ 真ん中のド、`G4` ＝ ソ、`C5` ＝ 1オクターブ上のド。`#`は半音上（例：`F#4`）。`R` ＝ 休み。
- 長さ ＝ 拍の数。省略すると1拍。`:2` ＝ 2拍、`:.5` ＝ 半拍。
- 同時に落とす音は `+` でつなぐ（長さは最後に1つ書く）。例）`G4+C4:2` ＝ ソとドを同時に（2拍）。先に書いた音を、メロディとして扱う。
- 落ちてくる位置と鳴る音を分けるときは `＝`（半角の `=` で書く）を使う（5.2）。`＝` の左 ＝ 落ちてくる位置の音（1つ）、右 ＝ 叩いたときに鳴る音（`+` でいくつでも）。ウイルスは1匹。長さは最後に1つ書く。
  - 例）`F#5=A#3+F#4:.5` ＝ F#5 の位置に1匹（半拍）。叩くと A#3 と F#4 の和音が鳴る。
  - 例）`C5=C6:.25` ＝ C6 の音を、C5 の位置に落とす（同じキーが続きすぎないように、位置を散らす）。
  - 薄いメロディは、右に最後に書いた音を鳴らす（7章）。
- 同時に落とすウイルスの1匹ずつに和音を鳴らしたいときは `&` でつなぐ（5.2 の 9）。`&` で区切った1つずつが1匹で、それぞれに `＝` が使える。長さは最後に1つ書く。
  - 例）`B5=B4+D5+G5&G3=G2+G3:.75` ＝ B5 の位置と G3 の位置に1匹ずつ（0.75拍）。B5 の位置の1匹を叩くと B4・D5・G5、G3 の位置の1匹を叩くと G2・G3 が鳴る。
  - `+` との違い：`+` は1匹ずつ自分の音を1つだけ鳴らす。`&` は1匹ずつ、`＝` の右の音を全部鳴らせる。
- 例）`C4 C4 G4:2 R` ＝ ド・ド・ソ（2拍）・休み（1拍）。

`chords` の書き方：
- `chart` と同じ「名前:長さ」の並び。長さを省略すると1拍。長さの合計は、`chart` の長さの合計と同じにする。
- コード名 ＝ 根音（C D E F G A B。`#`は半音上）＋ 短調なら `m` ＋ セブンスなら `7`。例）`C` ＝ ドミソ、`Am` ＝ ラドミ、`G7` ＝ ソシレファ。
- `R` ＝ 伴奏なし（ベースと和音を鳴らさない。7章）。例）`R:4 C:4` ＝ 最初の4拍は伴奏なし、次の4拍は C。
- 例）`C:4 F:2 C:2` ＝ C（4拍）・F（2拍）・C（2拍）。

### 8.2 ランキング（`ranking.js` の `Ranking`）

| 項目 | 仕様 |
| --- | --- |
| 保存先 | LocalStorage。**曲ごとに**キー `yumekawa_hs_0`、`yumekawa_hs_1`、`yumekawa_hs_2`（番号は `SONGS` の何番目か） |
| 件数 | 曲ごとに上位10件（スコア降順） |
| 記録の形 | `{ s: スコア, r: 防衛率(%), at: 登録時刻（ミリ秒、Date.now()）, n: 名前 }`。`n` の初期値は「ななし」 |
| 登録 | プレイ終了時に、名前「ななし」で自動で登録する（HP0で終了した場合も登録する）。10位以内なら、リザルト画面で名前を入れられる【できれば】。決めた名前は `Ranking.setName` で記録に書き込む |
| 名前 | 6文字まで。前後の空白は取り除き、空なら「ななし」。画面に出すときは `textContent` を使う（HTMLとして解釈させない） |
| 表示形式 | リザルト：1行に「順位　名前　◯点　◯%」 |
| 保存できない場合 | 読み込みに失敗したら空として扱い、書き込みに失敗しても無視する。ゲームは最後まで動き、リザルトには今回の記録だけが並ぶ |

### 8.3 本日のトップ3

- 「本日」＝ 記録の `at` の日付が、今日の日付と同じこと。
- 曲ごとに、今日の記録をスコアの高い順に上から3件、「メダル（1位＝金、2位＝銀、3位＝銅）・名前・◯点」で表示する。記録がない行は「--」を薄く表示する。名前は `textContent` で入れる。
- 曲の列は、難易度順（星の少ない順）に左から並べる。曲が6曲以上のときは、いちばんやさしい2曲を1列にまとめ、それぞれトップ1だけを表示する（列は5列になり、文字を小さくする）。
- 曲名の札の色は、曲の星の数で決める：★1 ピンク、★2 オレンジ、★3 黄色、★4 エメラルドグリーン、★5 水色、★6 ラベンダー（曲データのラベルの色とそろえる。5.1）。
- タイトル画面を表示するたびに、曲ごとに読み直す。
- 記録は曲ごとに上位10件だけ残る（8.2）ので、前の日やテストの記録で10件が埋まっていると、当日の記録が本日のトップ3に出ない。そのため、展示の日の朝に、スタッフ用リセット（3.2）で記録を消す（運用で決めた）。

### 8.4 セキュリティ豆知識（`tips.js` の `TIPS`）【できれば】

- `TIPS` は文字列の配列。1つ40文字くらいまで（2行に収まる長さ）。10個くらいが目安。
- 中学生にも分かる言葉で書く。内容は、IPA（情報処理推進機構）などの信頼できるページで確かめる。
- リザルト画面を表示するたびに、ランダムに1つ選ぶ。

## 9. 非機能仕様

| 項目 | 仕様 |
| --- | --- |
| ブラウザ | Chrome |
| 解像度 | 横1920px（16:9）で余白なし。他の比率では余白が出る。縦サイズは決めず、1920×1080 と 1366×768 でテストする |
| 性能 | 30fps以上を目標とする。描画は `transform` で動かし、ウイルスの数は同時に画面内の分だけに限る |
| 音と判定の同期 | 判定・ミス・ウイルスの位置はすべて Web Audio の時計で計算する |
| 堅牢性 | LocalStorage が使えなくてもゲームは最後まで動く（8.2） |

## 10. 内部構成（部品のつなぎ目）

担当をまたぐ呼び出しは、次の関数だけにする。ここに書いていない関数を、他のファイルから呼ばない。

### 10.1 ファイル間の呼び出し

| 関数・データ | 内容 | 呼ぶ側 → 持つ側 |
| --- | --- | --- |
| `SONGS` | 曲データの配列（8.1） | screens.js、game.js → charts.js |
| `Game.start(k)` | k番目の曲でプレイを始める。準備ができたら、プレイ画面に切り替えて、Space を待つ（3.4） | screens.js → game.js |
| `Game.stop()` | プレイを中断する（ループ停止、音停止）。結果は出さない | screens.js → game.js |
| `Game.key(code)` | プレイ中のキー入力（`KeyboardEvent.code`）を渡す。開始前は Space で曲を始める。開始後は、対応するレーンがあれば叩く | screens.js → game.js |
| `Game.onFinish` | ゲーム終了時に game.js が呼ぶ関数。screens.js が中身を設定する | game.js → screens.js |
| `Ranking.add(k, s, r)` | k番目の曲に記録（スコア s、防衛率 r、名前「ななし」）を追加して保存し、追加した記録 `{s, r, at, n}` を返す | screens.js → ranking.js |
| `Ranking.setName(k, at, n)` | 【できれば】k番目の曲の、登録時刻が `at` の記録の名前を `n` にして保存する | screens.js → ranking.js |
| `Ranking.top10(k)` | k番目の曲の上位10件を、スコアの高い順の配列で返す | screens.js → ranking.js |
| `Ranking.todayTop(k)` | k番目の曲の本日のトップ（記録）を返す。なければ `null` | screens.js → ranking.js |
| `Ranking.reset()` | 全曲の記録を消す | screens.js → ranking.js |
| `TIPS` | 【できれば】豆知識の文の配列（8.4） | screens.js → tips.js |
| `Screens.show(name)` | 画面を切り替える（`'title'`／`'select'`／`'play'`／`'result'`） | game.js・自分自身 → screens.js |

### 10.2 ゲーム終了時に渡す結果（`Game.onFinish(result)`）

| 項目 | 内容 |
| --- | --- |
| `k` | 曲の番号 |
| `score` | スコア |
| `hit` | 撃退したノーツ数 |
| `total` | 全ノーツ数 |

| `dead` | HPが0で終了したか（`true`／`false`） |
